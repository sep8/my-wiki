# PageIndex Chat

## Summary
The end-user web product at `chat.pageindex.ai` — a ChatGPT-style interface for chatting with one or more long documents, built on the [[reasoning-based-rag]] framework. Distinct from [[pageindex-mcp]] (developer integration) — Chat does not share files or usage with MCP.

## Explanation
Pitched as: "chat with multiple super-long documents without worrying about limited context or context rot" ([[context-rot]]). Programmatic access to the same kind of conversational interface is available through the [[chat-api]].

Related blog: "Introducing PageIndex Chat" (Oct 20, 2025), and the case study "PageIndex vs ChatGPT 5.1: A Case Study on Long-Document QA" (Nov 30, 2025).
