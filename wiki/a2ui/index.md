# A2UI

> **Scope note for coding agents.** This topic documents the **official
> upstream Google A2UI** (`@a2ui/web_core`, `@a2ui/react`, `@a2ui-sdk/*`,
> the Python SDK). It does **not** describe this monorepo's own `a2ui-*`
> packages under `packages/`, which are a local wrapper over upstream A2UI.
> Do not assume claims here hold verbatim in the wrapper — when reasoning
> about local code, read the package source directly.

> **Version note.** These pages describe the stable v0.9 protocol family. The
> newer upstream checkout under `raw/a2ui/google-A2UI/` identifies v0.9.1 as
> the current production release and v1.0 as a release candidate.
