# ArcGIS Map

Source set: ArcGIS Maps SDK for JavaScript 2D maps, Map Components, basemap, web map, graphics, and component reference clippings under `raw/arcgis-map/`.

## Foundations

- [[map-concepts]] - what a 2D map contains and the two main creation paths.
- [[setup-and-authentication]] - loading the SDK, using npm/Vite, and access tokens.
- [[map-component]] - the `<arcgis-map>` component, important attributes, slots, methods, and lifecycle.

## Map Content

- [[web-maps]] - loading ArcGIS Online or Enterprise web maps with `item-id` or `WebMap`.
- [[basemaps]] - built-in basemaps, custom basemap styles, and basemap sessions.
- [[graphics]] - adding point, line, polygon, and popup graphics with `GraphicsLayer`.

## Interaction And UI

- [[view-and-events]] - view readiness, viewpoint updates, `goTo`, clicks, hit tests, and popups.
- [[ui-components]] - map slots, zoom, legend, layer list, search, and Calcite shell layouts.
